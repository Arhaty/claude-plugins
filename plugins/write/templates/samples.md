# Writing samples

Text this project has sent or published that reads the way it should. The `write` skill reads this
file before drafting anything longer than two lines and takes length, structure and what to cut
from it. Written by `/write:setup`; edit it freely.

Put each sample under its own `##` heading that names the channel and the context, and paste the
text exactly as it went out. The skill ignores this file until it has one. Three or four good
samples teach more than twenty average ones; remove one that no longer sounds right.
